# API 直连使用指南

本指南适用于 `DEV/2.0` 分支的“API 直连”页面。连接设置只提供 **OpenAI 标准接口（Chat Completions）** 这一种协议；你需要自己填写接口地址、模型 ID 和密钥。知更·Paper 仍可像以前一样只生成和复制提示词；填写 API 是可选功能。

## 先了解数据会去哪里

1. 访问网站时，静态页面由网站托管方提供。新版图标字体和样式由本站自身提供，不再从 Google Fonts 或 jsDelivr 加载。
2. 只有你主动点击“直接发送给目标服务商”、选题助手的“生成 3 个选题建议”或“发送追问”后，浏览器才向你填写且确认过的 HTTPS 接口发出请求。请求包含 **API 密钥、模型 ID 和本次提示词或选题对话**。程序没有本站代理或中转接口，也不会在 CORS 失败时自动改走其他服务器。
3. 收到的回答在浏览器中显示。勾选“保存在此浏览器”时，提示词、回答和服务商返回的 Token 用量保存在当前浏览器的 IndexedDB；密钥从不写入这份记录。关闭保存选项后，新请求不创建本机记录。
4. 本站不能约束模型服务商的日志、账单或数据政策。浏览器扩展、设备环境、网络运营方和日后由网站托管方提供的页面代码也在本站代码所能保证的范围之外。因此，“直连”表示**应用没有自建中转服务器**，并不表示密钥在浏览器中具有服务端密钥的安全等级。

OpenAI [明确建议不要在浏览器或移动客户端部署长期 API 密钥](https://help.openai.com/en/articles/5112595-best-practices-for-api-key-safety)。如果这项风险不可接受，请继续使用原有的“复制提示词”模式，或自行部署可信后端。直连模式适合使用专用、低额度、可撤销的密钥进行个人使用；不能承诺绝对防泄露。

## 第一步：准备密钥和额度

- 在你选用的模型服务商**官方网站**开通 API 并创建一枚专用于知更·Paper 的密钥。不要使用与你其他项目共用的重要主密钥。
- 了解该服务商的计费方式，尽可能设置低额度、权限限制和有效期。不同服务商的控制项各不相同。
- OpenAI 用户可前往[官方 API 密钥页面](https://platform.openai.com/api-keys)。官方说明了[项目密钥、权限和限额](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform)。获取密钥后先安全保存；不要发给网站作者、贴进公开仓库或截图分享。
- 使用完毕或怀疑泄露时，到服务商后台撤销并更换密钥。本站的“清除本页密钥”只清理当前浏览器内存，不会撤销服务商后台的密钥。

## 第二步：填写接口地址和模型 ID

打开“API 直连”标签：

1. 页面默认填入 OpenAI 官方的完整地址：`https://api.openai.com/v1/chat/completions`。如使用支持同一 Chat Completions 协议的服务，请从该服务的官方文档复制**完整**接口地址；连接设置没有服务商预设选项。这是接口地址，不是聊天网页地址。
2. 地址必须使用 HTTPS、以 `/chat/completions` 结尾，且不能含账号、密码、查询参数或 `#` 片段。页面会显示本次请求的目标域名。请对照服务商官网核对，不要把密钥发往来源不明的“兼容接口”。
3. 从服务商的当前模型文档复制模型 ID。模型列表会更新，因此本站不预填可能过期的模型名；ChatGPT 等网页订阅也不一定包含 API 额度。
4. 粘贴 API 密钥。密钥输入框是密码框，程序仅在当前页面内存中持有它；刷新或关闭页面后需要重输。密钥不会写入 URL、本地存储或使用记录。
5. 勾选域名确认框。每次修改接口地址都需要重新确认，防止密钥被误送到新域名。

**兼容性要求：**服务商必须允许浏览器跨域调用该接口（CORS）。带 `Authorization` 请求头的浏览器调用通常需要预检请求；服务商不开放时，纯静态网站无法绕开这一限制。本站不会添加隐形代理。参见 [MDN 的 CORS 说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)。

## 第三步：发送第一条提示词

1. 在“生成提示词”“论文审阅”或“写作优化”页生成提示词，点击“在本页使用”；也可以直接在“API 直连”页粘贴文字。
2. **先用一条不含敏感材料的短提示词测试**，确认地址、模型和费用设置都正确。测试请求也可能收费。
3. 检查输入框中将要发送的全文；尤其注意其中是否包含论文草稿、个人信息或未公开材料。
4. 点击“直接发送给目标服务商”。每次点击只发送一次非流式 Chat Completions 请求，不自动重试。等待期间可取消请求，但取消不保证服务商没有处理或计费。
5. 回答在页面中以纯文本显示，不执行其中的 HTML 或脚本。若服务商返回 Token 用量，页面会显示总数；费用和官方统计以服务商后台为准。

## 第四步：管理本机记录

- 默认勾选“保存在此浏览器”：成功请求的提示词、回答、模型 ID、服务商域名、时间及服务商返回的 Token 用量进入当前浏览器的 IndexedDB。**密钥不入库。**
- 不想留下新记录时，在发送前取消勾选。当前页面的回答仍会显示，刷新后消失。
- 可逐条删除或清空全部。浏览器清理本站的站点数据后，本机记录也会消失；本站没有云端恢复功能。
- 共用电脑上的其他本地用户、浏览器扩展或能访问此浏览器配置文件的程序，可能读取本机记录。请根据资料敏感度决定是否保存。

## 使用论文选题助手

1. 先在“API 直连”页填入接口地址、模型 ID 和本页密钥，再打开“选题助手”。两处使用同一组连接信息，协议仍只有 OpenAI 标准 Chat Completions。
2. 核对选题助手显示的请求域名并勾选确认。填写学科或研究兴趣；补充论文类型、可用材料、研究方法和完成时间能让建议更具体。
3. 点击“生成 3 个选题建议”。助手会比较研究问题、方法、资料需求、可行性与风险。它**不能联网检索或核验文献和数据**，这些事项会标为待核实。
4. 用追问框让助手收窄范围、比较资料需求或整理研究路径。每次追问都会连同背景和最近 5 轮对话直接发送给目标服务商，可能产生费用。
5. 自己核实资料后，填写最终采用的题目和研究问题，点击“带入论文参数”。助手不会自动替你定题。

选题对话仅在当前页面内存中保留，不写入“API 直连”的本机使用记录，刷新或关闭页面后清除。模型服务商仍可能按其政策保留请求。

## 常见问题

| 页面提示 | 常见原因与处理 |
| --- | --- |
| 401 | 密钥错误、过期或已撤销。检查是否粘贴完整，并到服务商后台确认。 |
| 403 | 密钥权限不足、项目未启用该接口，或服务商拒绝请求。 |
| 404 | 接口路径或模型 ID 错误。复制服务商当前官方文档中的值。 |
| 429 | 超过额度、余额不足或触发速率限制。查看服务商后台。 |
| CORS / 网络错误 | 可能是跨域限制、证书或网络问题。本站不使用代理；请尝试受支持的接口，或改用复制提示词模式。错误本身不能证明请求一定没有抵达服务商。 |
| 本机记录不可用 | 浏览器禁用 IndexedDB、私人模式限制或存储空间不足。可关闭保存选项继续使用；回答不会自动上传到本站。 |

## 怎样自己核对请求去向

打开浏览器开发者工具的“网络 / Network”面板，过滤 `Fetch/XHR`，再发送一条**不含秘密的测试提示词**。你应看到请求目标是自己填写的服务商地址；本项目的请求实现位于 [`src/api/directClient.js`](../src/api/directClient.js)。检查完不要分享含 `Authorization` 头的网络抓包或 HAR 文件。页面初次载入仍会从网站托管方获取静态资源；这不等于 API 密钥或提示词经过托管方的应用服务器。

仓库中的 [`public/_headers`](../public/_headers) 为 Cloudflare Pages 配置了 CSP 等安全响应头。自定义兼容接口需要允许用户填写不同的 HTTPS 域名，因此 CSP 的 `connect-src` 允许 HTTPS；真正的请求目标由页面上显示并由用户确认的完整地址决定。部署到其他静态主机时，需要自行配置对应的响应头。
